# Thesis Research Project

This repository provides a public overview of my thesis research project in multimodal machine learning.

## Project Overview

This research explores efficient multimodal inference and dynamic routing strategies, with experiments conducted on multimodal benchmark datasets.

The implementation was developed by extending prior research code, including:

* [DynMM](https://github.com/zihuixue/DynMM)
* [MultiBench](https://github.com/pliang279/MultiBench)

My research builds additional methods, experimental pipelines, evaluation procedures, and analyses on top of these foundations.

## Code Availability

The research source code is currently not publicly available due to thesis embargo requirements and third-party code licensing considerations.

A cleaned version of the implementation may be released in the future, subject to institutional requirements and permission associated with the upstream code.

## Status

Thesis research completed. Public documentation and project information will be updated when additional materials can be released.
